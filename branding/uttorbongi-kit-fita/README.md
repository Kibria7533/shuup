## ফন্ট (Google Fonts, ফ্রি)
- বাংলা শিরোনাম: Tiro Bangla

- ইংরেজি: Jost (Medium 500)

## ফোল্ডার
- svg/ — যেকোনো সাইজে ঝকঝকে; ওয়েবসাইটে আগে এগুলোই ব্যবহার করুন
- png/ — যেখানে SVG চলে না (Facebook, Daraz, Shopify লোগো আপলোড ইত্যাদি)
- favicon/ — ব্রাউজার ট্যাব ও মোবাইল হোম-স্ক্রিন আইকন + site.webmanifest
- social/ — OG শেয়ার ইমেজ, প্রোফাইল ছবি, ফেসবুক কভার
- head-snippet.html — ওয়েবসাইটের <head>-এ বসানোর কোড

## লোগোর ধরন
- logo-full — পূর্ণ লোগো (UTTORBONGI সহ): ফুটার, প্যাকেজিং, ইনভয়েস, সোশ্যাল
- logo-header — UTTORBONGI ছাড়া, ছোট জায়গার জন্য: ওয়েবসাইটের হেডার
- icon — শুধু "উব": ফেভিকন, অ্যাপ আইকন, প্রোফাইল ছবি
- color = হালকা ব্যাকগ্রাউন্ডে, white = গাঢ় ব্যাকগ্রাউন্ডে, black = এক রঙের প্রিন্ট/স্ট্যাম্প

## নিয়ম
- লোগোর চারপাশে যথেষ্ট ফাঁকা জায়গা রাখুন
- হেডারে লোগো কমপক্ষে ৪০px উঁচু; এর ছোটে শুধু আইকন ব্যবহার করুন
- লোগো টেনে লম্বা/চ্যাপ্টা করবেন না, রং বদলাবেন না
